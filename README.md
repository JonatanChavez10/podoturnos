# Podología Blanca

Sitio web desarrollado para un consultorio de podología.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries

## Funcionalidades

- Información sobre servicios
- Formulario de solicitud de turnos
- Diseño responsivo
- Navegación interna

## Contenido del sitio

- Inicio
- Servicios
- Solicitud de turnos
- Registro de usuarios
- Contacto
